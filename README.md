# LeetCode & Codeforces Task Viewer

Приложение для просмотра и решения задач с LeetCode и Codeforces. Поддерживает автоматический перевод описаний задач с английского на русский язык, оценку качества кода с помощью нейросети и предоставляет рекомендации по его улучшению. Также реализован личный кабинет пользователя с сохранением прогресса и историей решений.

## Технологии

- React  
- TypeScript  
- Material-UI  
- MyMemory Translation API  
- OpenRouter API (нейросетевой анализ кода)  
- XAMPP (локальная база данных)

## Требования

- Node.js (версия 14 или выше)  
- npm  
- Доступ к интернету для работы с API  
- XAMPP (MySQL и Apache)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Ivanokblya/LP
   cd LP
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## Запуск

1. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

2. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

3. Запустите XAMPP и убедитесь, что MySQL и Apache включены. Настройте базу данных согласно конфигурации проекта.

## Использование API

### MyMemory Translation API
Используется для автоматического перевода описаний задач.  
- Максимальная длина запроса: 500 символов  
- Ограничение по количеству запросов в день  
- Не требует API ключа

### LeetCode API
Используется GraphQL API через локальный сервер-прокси. Это позволяет избежать ограничений и обеспечить безопасность запросов.

### Codeforces API
Интеграция с официальным API платформы Codeforces для получения задач, тестов и статистики.

### OpenRouter API
Используется для анализа отправленного кода с помощью нейросети:  
- Оценка качества решений  
- Автоматическая генерация рекомендаций  
- Работа осуществляется через OpenRouter API

## Функциональность

- Просмотр случайных задач с LeetCode и Codeforces  
- Перевод описаний на русский язык  
- История решений и отслеживание прогресса  
- Фильтрация задач по уровню сложности  
- Личный кабинет с отображением статистики пользователя  
- Интеграция с ИИ для анализа решений
